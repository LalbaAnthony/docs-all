# Docs

Just a bunch of docs I find useful to have at hand.

## Contributing

- `.pdf` files are generated from `.md` files using https://apitemplate.io/pdf-tools/convert-markdown-to-pdf/.
- To edit a doc, modify the `.md` file and regenerate the `.pdf` file.
- Assets should always be stored in the `assets` folder and linked using the https://raw.githubusercontent.com/ CDN URL, for example: `chrome/download-extension-from-github/assets/download-screenshot.png` becomes `https://raw.githubusercontent.com/LalbaAnthony/antho-docs/main/chrome/download-extension-from-github/assets/download-screenshot.png`.
