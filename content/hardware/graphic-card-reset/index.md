# Modern Graphics Card BIOS Reset

- Look for a `BIOS_SW` or `BIOS_RESET` button on the card.
- If it has a button:
  - Turn off the computer and remove the power cable.
  - Use it to reset the graphics card BIOS.
- Use another graphics card to run the computer.
  - Install NVIDIA NVFlash or AMDVBFlash depending on your graphics card brand.
  - Download the latest BIOS for your graphics card from the manufacturer's website.
  - Use the software to flash the BIOS with the downloaded file.
